# Model registry legal and compliance notes

Fixture-first model registry coverage is not live legal approval.

Before a model registry provider can be promoted beyond fixture-first status, it
needs evidence for identity, tenant/account boundary, region and data residency,
export-control posture, data-class rules, audit logging, retention, cost/FinOps,
and model-provider terms.

This package deliberately denies live inference and regulated-live data classes
by default. Bob11 owns ask-provider runtime. Bob14 only exposes registry facts.
