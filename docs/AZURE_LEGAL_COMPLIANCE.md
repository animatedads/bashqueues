# Azure legal and compliance posture

This package provides proposed Azure legal/compliance mapping only. Status is **mapped pending validation**.

Areas to map before acceptance:

- region and sovereignty allowlists;
- GDPR and UK DPA posture;
- retention and deletion evidence;
- audit/event logging evidence;
- cross-border review flags;
- customer-managed key / HSM posture where required;
- export-control/ITAR-style class labels where in scope;
- shared-responsibility assumptions.

Do not market Azure classes as compliant from this package alone. Compliance claims require primary-source validation, organisation policy, and explicit acceptance.
