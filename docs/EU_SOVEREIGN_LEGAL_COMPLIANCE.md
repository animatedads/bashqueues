# EU sovereign cloud legal/compliance posture

Status: mapped pending validation.

This package is a governance/provider-contract starter pack. It does not claim that any provider, class, region, or workload is legally compliant.

Legal/compliance rails to map before acceptance:

- GDPR/data-protection posture
- UK DPA where UK data subjects or UK operations are involved
- data location and cross-border transfer review
- retention/deletion evidence
- auditability and access evidence
- provider-subprocessor and support-access model
- signed URL/token redaction
- security incident and breach evidence requirements

Do not market a provider as sovereign, compliant, or first-tier from these templates alone. Convert only primary-source-validated requirements into accepted class criteria.
