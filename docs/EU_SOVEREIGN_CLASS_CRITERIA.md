# EU sovereign cloud class criteria

EU sovereign-cloud classes are examples for workloads where European hosting, jurisdictional posture, data-protection evidence, and bounded provider contracts matter.

Candidate class controls:

- provider allowlist: OVHcloud, Scaleway, Hetzner, Open Telekom Cloud
- EU/UK region allowlist
- legal framework mapping: GDPR, UK DPA, sector-specific retention where applicable
- audit/logging required
- artifact handoff redaction for signed URLs/tokens
- network restriction evidence
- cost/FinOps guardrails

These class templates are not proof of compliance. They are contract examples pending validation.
