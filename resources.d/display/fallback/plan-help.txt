Usage: queue plan scan PATH [--json]
       queue plan explain PATH [--json]
       queue plan build PATH --output DIR [--json]
       queue plan validate DIR|normalized.json [--json]

queue plan treats native bashqueues plans, cloud manifests, HPC scheduler files,
workflow YAML/HCL and legacy scheduler directives as operational intent. It
normalizes supported sources into queue.control_plan.v1 and stages inert plan
artifacts only. It does not submit jobs, apply cloud resources, read secrets,
or create a parallel scheduler path. Cron-like input must bridge to existing
bashqueues cron support. DGX/GPU cloud and workflow plans require explicit
policy review before any future apply path.
queue plan status PATH [--json]
  Summarise exported runtime/job/status evidence as reviewable plan facts. Static only: no SDK/API/CLI/WinRM/SMB/RPC/REST polling, no credentials, no logs, no mutation.
queue plan sources PATH [--json]
  Explain plan/job extraction-source contracts for recognised exported evidence and the boundary to future collectors.
queue plan evidence PATH [--json]
  Produce a supplied-file evidence bundle separating plan definitions from runtime/job status facts, with source contracts, policy gates and no-live attestations.
